# Itzfizz Scroll-Driven Hero Animation

Live demo: https://knandhini2208.github.io/itzfizz-hero/

A scroll-driven hero section built with React, Vite, Tailwind CSS and GSAP (ScrollTrigger).

## Features
- Staggered headline reveal and animated stat counters on load
- Car movement, road motion and headline highlight tied to scroll progress (scrubbed, eased)
- Transform-based animation for smooth performance
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```
